# Aturan Proyek (Project Rules)

## Workflow Git Otomatis
- **Setiap kali ada perintah atau perubahan kode yang selesai dilakukan**:
  1. Lakukan `git add` untuk file yang diubah.
  2. Lakukan `git commit` dengan pesan commit yang jelas dan relevan.
  3. Lakukan `git push` langsung ke remote GitHub (`origin main` atau branch yang sedang aktif).
